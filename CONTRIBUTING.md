# Contributing

This is primarily a personal portfolio project, but suggestions and improvements are welcome.

## Ways to contribute

- 🐛 **Found an issue?** Open a GitHub Issue describing what's wrong.
- 💡 **Have an idea for a new view or metric?** Open an Issue to discuss it first.
- 🔧 **Want to submit a fix or enhancement?**
  1. Fork the repo
  2. Create a branch: `git checkout -b feature/your-idea`
  3. Commit your changes: `git commit -m "Add: your change"`
  4. Push: `git push origin feature/your-idea`
  5. Open a Pull Request

## Notes

- The dashboards themselves are built and published on Tableau Public — this repo hosts documentation, screenshots, and the source dataset.
- Keep PRs focused and small where possible.
